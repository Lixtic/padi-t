What Basic 7 Computing covers

Topics by week, from the scheme of learning that GuidEd uses to write each plan.

Term 1

  • Weeks 2–5: Introduction to Computing: Components of Computers and Computer Systems
    B7.1.1.1. Examine the parts of a computer; B7.1.1.2. Demonstrate the use of the features of the Windows Desktop
  • Weeks 6–8: Introduction to Computing: Technology in the Community
    B7.1.2.1. Demonstrate the use of Technology in the community
  • Weeks 9–12: Introduction to Computing: Health and Safety in Using ICT Tools
    B7.1.3.1. Demonstrate how to apply Health and Safety measures in using ICT Tools

Term 2

  • Weeks 2–3: Productivity Software: Introduction To Word Processing
    B7.2.1.1. Demonstrate how to use Microsoft Word (Formatting Text)
  • Weeks 4–6: Productivity Software: Introduction To Presentation Software
    B7.2.2.1. Demonstrate how to use Microsoft PowerPoint (Editing): Introduction to PowerPoint.; B7.2.2.2. Demonstrate how to use Microsoft PowerPoint (Formatting)
  • Weeks 7–11: Productivity Software: Introduction To Electronic Spreadsheet
    B7.2.3.1. Demonstrate how to use the Spreadsheet (Editing Worksheets); B7.2.3.2. Demonstrate how to format a worksheet; B7.2.3.3. Demonstrate how to use spreadsheet formula
  • Week 12: Communication Networks: Computer Networks
    B7.3.1.1. Identify the concept of computer networking for global communications

Term 3

  • Week 2: Communication Networks: Computer Networks
    B7.3.1.1. Identify the concept of computer networking for global communications
  • Week 3: Communication Networks: Internet And Social Media
    B7.3.2.1. Demonstrate the use of Social Networking and Electronic Mail
  • Weeks 4–5: Communication Networks: Information Security
    B7.3.3.1. Recognise data threats and means of protection B7.3.3.1. Recognise data threats and means of protection
  • Weeks 6–7: Communication Networks: Web Technologies
    B7.3.4.1. Demonstrate the use of a Web Browser (Search engine)
  • Weeks 8–9: Computational Thinking: Introduction To Programming
    B7.4.1.1. Show an understanding of the concept of programming
  • Week 10: Computational Thinking: Algorithm
    B7.4.2.1. Analyse the correct step-by-step procedure in solving any real-world problem
  • Week 11: Computational Thinking: Robotics
    B7.4.3.1. Discuss Robot Intelligence Concepts
  • Week 12: Computational Thinking: Artificial Intelligence
    B7.4.4.1. Discuss Artificial intelligence concepts
